# 선택 템플릿

모든 지원 건에 필요하지는 않은 문서들. **필요할 때 해당 파일만 상위 폴더(지원 건 폴더)로 옮겨 쓰고, 쓰지 않으면 이 `optional/` 폴더는 지운다.**

* [career-statement.md](./career-statement.md) - 경력기술서를 따로 제출할 때. 제출본 스냅샷.
* [research-briefing.md](./research-briefing.md) - 채용설명회 · 현직자 대화 · 커피챗에서 직접 들은 내용 정리.
* [interview-personas.md](./interview-personas.md) - 면접관 유형(압박 · 인사 · 실무)별 예상 질문.
* [interview-review.md](./interview-review.md) - 면접(AI 면접 포함)을 마친 뒤의 상세 복기.
