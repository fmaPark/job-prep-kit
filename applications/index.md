# 지원 현황

회사 폴더 하나 = 지원 건 하나.
폴더명: `YYYY-MM-회사명-직무` (예: `2026-09-토스-백엔드`, `2026-10-오늘의집-마케팅`)
새로 만들 때는 `_template/`을 통째로 복사한다. 관심 · 지원안함 단계는 `meta.md` 한 장만 있어도 된다.

**상태의 정본은 각 회사 폴더의 `meta.md`다.** 아래 `AUTO` 표시 사이(파이프라인 · 이번 주 일정 · 지원하지 않기로 한 곳 · 누적 결과)는 `python3 build-dashboard.py`가 다시 쓰므로 손으로 고치지 않는다. 「지원별 상세 메모」만 직접 쓴다.
