# 지원 현황

회사 폴더 하나 = 지원 건 하나.
폴더명: `YYYY-MM-회사명-직무` (예: `2026-09-토스-백엔드`, `2026-10-오늘의집-마케팅`)
새로 만들 때는 `_template/`을 통째로 복사한다.

## 파이프라인

지원 상태는 각 회사 폴더의 `meta.md`에만 적는다. 여기에 표로 다시 옮겨 적지 않는다(두 곳에 적으면 반드시 어긋난다).
전체 현황은 대시보드에서 본다: `python3 build-dashboard.py` → `dashboard.html`.

상태값: `관심` → `서류작성` → `지원완료` → `필기·과제` → `면접` → `결과대기` → `합격`/`불합격`
세부 단계(2차 면접, 인턴 전환 등)는 `meta.md`의 `stage_note`에 적는다.

## 누적 결과

결과가 나올 때마다 손으로 갱신한다. 대시보드는 이 표를 계산하지 않는다.

| 지표 | 값 |
|---|---|
| 지원 | 0건 |
| 서류 통과 | 0건 |
| 필기·과제 응시 | 0건 |
| 필기·과제 통과 | 0건 |
| 면접 | 0건 |

> 이 표가 어디서 막히는지를 알려준다. 서류에서 끊기는지, 필기·과제에서 끊기는지에 따라
> 다음에 시간을 쓸 곳이 완전히 달라진다.
