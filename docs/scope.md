# 이 저장소가 하지 않는 것

이 저장소는 경험을 모으고 정리해 근거로 매핑하는 도구입니다. 글의 색, 사실의 진위, 최종 판단은 사용자 몫입니다.
아래 표는 항목마다 **해 주는 것 → 안 해 주는 것**의 경계와, 그 빈자리를 사용자가 어떻게 채우는지 정리한 것입니다.

## 직접 키우는 방법

빈자리는 대부분 저장소 안에서 채울 수 있습니다.

- **글의 색 · 작성 습관** — [자소서 작성 규칙](/library/cover-letter-rules.md)과 [포트폴리오 작성 규칙](/library/portfolio-rules.md) 끝의 「내 규칙」에 날짜와 함께 한 줄씩 덧붙입니다. AI는 작업 전에 이 문서를 읽으므로 다음 초안부터 반영됩니다.
- **판단 기준** — [/me/target-criteria.md](/me/target-criteria.md)의 예시 값을 본인 기준으로 바꿉니다. 같은 예외가 반복되면 그때 기준을 고칩니다.
- **AI 규칙 자체** — [/CLAUDE.md](/CLAUDE.md)는 자기 상황에 맞게 고쳐 써도 됩니다. 자주 쓰는 요청은 [플레이북](/playbook.md) 「자주 쓰는 요청 문장」에 추가합니다.
- **도구 쪽 확장** — 쓰는 AI 도구가 스킬 · 커스텀 지침 · 프로젝트 지침을 지원하면, 반복하는 요청을 거기에 등록해 둡니다.
