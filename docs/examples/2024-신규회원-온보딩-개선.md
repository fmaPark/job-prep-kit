# 상황 (S)

2024년 3~5월, 30명 규모 구독 서비스 스타트업의 운영팀 인턴. 가입 후 7일 안에 첫 구독을 시작하는 비율이 낮다는 문제가 팀 회의 안건으로 올라와 있었다.

# 과제 (T)

가입 직후 어느 단계에서 이탈하는지 찾아내고, 개발 리소스 없이 운영팀이 바꿀 수 있는 개선안을 하나 실행하는 것.

# 행동 (A)

- 내가 직접 한 것:
  - 가입 후 7일 동안의 행동 로그를 스프레드시트로 정리해 단계별 이탈 지점을 표로 만들었다.
  - 이탈이 가장 큰 "프로필 입력" 단계 사용자 12명에게 직접 연락해 인터뷰했다.
  - 환영 메일 문구와 발송 시점을 바꾼 A/B 테스트를 설계하고 4주간 운영했다.
- 팀이 한 것:
  - 메일 발송 도구 설정은 마케팅 담당자가 했다.
  - 최종 적용 여부는 운영팀장이 결정했다.

# 결과 (R)

- 수치: 7일 내 첫 구독 전환율 8% → 11% (실험군 기준, 4주)
- 검증 방법: 실험군 · 대조군 각 약 600명. 사내 대시보드 수치를 팀장과 함께 확인. 캡처는 `me/assets/`에 보관.

# 배운 것

데이터로 "어디서" 이탈하는지는 찾을 수 있었지만 "왜"는 인터뷰에서 나왔다. 이후로는 숫자를 본 뒤 반드시 사용자 몇 명과 직접 이야기한다.

# 예상 꼬리질문

1. 3%p 상승이 우연이 아니라고 어떻게 판단했나? 표본 크기는 충분했나?
2. 메일 문구와 발송 시점을 동시에 바꿨는데, 둘 중 무엇이 효과를 냈는지 어떻게 구분하나?
3. 인터뷰 대상 12명은 어떻게 골랐고, 그 선택이 결과를 왜곡하지 않았나?
