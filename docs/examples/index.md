# 작성 예시

템플릿을 채우면 어떤 모양이 되는지 보여주는 **가상의 예시**다. 인물 · 회사 · 수치는 모두 지어낸 것이다.

* [경험 원자 예시](/docs/examples/2024-신규회원-온보딩-개선.md) - `me/experiences/`에 들어갈 파일 하나.
* [매핑표 예시](/docs/examples/strategy-example.md) - 회사 폴더 `strategy.md`의 핵심 부분.

## 쓰는 법

* 구조와 밀도만 참고한다. 문장을 베끼지 않는다.
* 이 폴더는 대시보드가 세지 않는다. `me/`나 `applications/`로 복사하지 않는다.
* AI에게도 이 폴더는 사실의 출처가 아니다. 사실은 `me/`에서만 가져온다.
