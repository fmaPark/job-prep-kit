# 우선순위 판단표

공고 하나를 100점 만점으로 채점한다. 가중치 합이 100이 되게 맞춘다.

| 기준 | 가중치 | 만점 조건 |
|---|---|---|
| (예: 일하는 방식 · 문화) | 25 |  |
| (예: 도메인 · 직무 적합) | 20 |  |
| (예: 회사 안정성) | 15 |  |
| (예: 쓰는 도구 · 방법론 적합) | 15 |  |
| (예: 연봉) | 10 |  |
| (예: 통근 · 근무 형태) | 10 |  |
| (예: 성장 여지) | 5 |  |

**판정선** (예시)

- **70점 이상** → 지원. 자소서에 시간을 쓴다
- **55~69점** → 조건부. 공고가 적을 때만. 자소서는 기존 재료 변형 수준으로
- **55점 미만** → 지원하지 않는다
- **하드 필터 위반** → 점수와 무관하게 지원하지 않는다

**미확인 항목 처리**

- 공고로 판단할 수 없는 판단표 항목은 **가중치의 절반**을 넣고, 그 항목을 0점과 만점으로 둔 **최저~최고 범위**를 함께 쓴다.
- 범위가 판정선에 걸치면 판정은 **"역질문 결과에 따라 갈림"**이다. 걸치는 항목을 면접 역질문 1순위로 둔다.
- **하드 필터 미확인은 위반으로 치지 않는다.** 역질문 1순위로 올린다.
- 이 문서에 없는 조건(근무 일정, 팀 규모 등)은 점수에 넣지 않고 **"기준 외 조건"**으로 따로 보고한다. 판단은 본인이 한다.

**개별 예외**

- 기준과 맞지 않는데 지원하기로 했다면, 그 이유를 해당 지원 건의 `meta.md` 메모에 적는다. 예외 한 건을 이유로 이 문서의 공통 기준을 바꾸지 않는다. 같은 예외가 반복되면 그때 기준을 고친다.
