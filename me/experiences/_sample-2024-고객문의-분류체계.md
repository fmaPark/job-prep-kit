# 무엇인가 (정의)

흩어져 있던 고객 문의 유형을 다시 나누고 담당 배정 규칙을 만든 일.

# 상황 (S)

문의 유형이 담당자마다 다르게 분류되어 같은 문의가 여러 사람에게 돌아다녔다.

# 과제 (T)

분류 기준을 하나로 맞추고, 유형별 담당 배정 규칙을 정한다.

# 행동 (A)

- 내가 직접 한 것: 최근 3개월 문의를 직접 읽고 유형 초안을 만들었다. 담당자 인터뷰로 초안을 고쳤다.
- 팀이 한 것: 배정 규칙의 최종 승인과 시스템 설정은 팀장과 개발 담당이 했다.

# 결과 (R)

- 수치: 재배정된 문의 비율이 줄었다(가상의 수치: 월 120건 중 30건 → 8건).
- 검증 방법: 문의 관리 도구의 재배정 기록을 월별로 셌다.

# 배운 것

분류 기준은 만드는 사람보다 쓰는 사람이 먼저 동의해야 지켜진다.

# 기여 경계

- 주장할 수 있는 것: 유형 초안 작성, 인터뷰 기반 수정, 재배정 비율 집계.
- 주장하지 않는 것: 시스템 설정, 배정 규칙의 최종 결정.

# 한계 · 쓰지 않을 것
